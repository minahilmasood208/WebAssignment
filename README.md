6. COMPLETE WEBSITE EXPERIENCE: MANDATORY ANIMATION SEQUENCE

This is the most important technical and visual requirement of the entire assignment.

The complete experience must follow this exact sequence:

Personal Branding / Hero → About Me → Animated Desktop Entrance → Desktop Website Screenshot → Desktop Full-Screen Zoom → Desktop Return → Animated Smartphone Entrance → Smartphone Falling Animation → Mobile Website Screenshot → Mobile Full-Screen Zoom → Smartphone Return → Contact Us.

The transitions should feel like a continuous visual story.

The visitor should experience the website progressively through scrolling.

Do not treat these as disconnected sections.

STAGE A: DESKTOP / LAPTOP ENTRANCE

As the visitor scrolls beyond the introductory and project-introduction content, a desktop/laptop device must enter the scene through animation.

Requirements:

- The desktop/laptop should appear progressively as the user scrolls.
- It should enter through a sophisticated animation.
- Use realistic device proportions and screen dimensions.
- Give it a premium appearance.
- Use appropriate depth, shadows, perspective, and lighting.
- The desktop should become the primary visual focus.

The animation must feel intentional, fluid, and professionally executed.

STAGE B: MY WEBSITE INSIDE THE DESKTOP

Once the desktop has appeared, display an image of my actual website inside its screen.

This image must be:

- My own website's homepage screenshot.
- A PNG image.
- Properly aligned inside the desktop screen.
- Scaled to fit the screen accurately.
- Clipped to the visible screen boundaries.
- Visually integrated with the device frame.

The image must look like a real website open on a desktop computer.

NON-NEGOTIABLE: The website screenshot is a PNG image, not a live website.

It must not be converted into an iframe, clickable webpage, or embedded interactive website.

The image should be easily replaceable.

Use a clearly named image asset such as:

"desktop-website.png"

STAGE C: DESKTOP WEBSITE ZOOM-IN ANIMATION

As the visitor continues scrolling:

1. The website screenshot initially remains inside the desktop screen.
2. The screenshot gradually begins enlarging.
3. With further scrolling, it expands beyond the desktop frame.
4. The desktop frame gradually disappears, recedes, or transitions away.
5. The screenshot progressively occupies more of the browser viewport.
6. Eventually, the screenshot reaches a full-screen presentation.

The effect must create the illusion that the visitor is moving into the website displayed inside the desktop.

This should be a cinematic, carefully choreographed zoom transition.

It must NOT look like an ordinary image simply increasing in size.

STAGE D: FULL-SCREEN DESKTOP PRESENTATION

At the end of the zoom animation:

- The desktop website PNG must occupy the entire viewport.
- It should appear large and clear.
- Preserve the image's original aspect ratio.
- Do not stretch or distort it.
- Avoid unnecessary cropping.
- The desktop version of my actual website must be displayed.

The transition must be smooth and synchronized with scrolling.

STAGE E: DESKTOP IMAGE RETURNS

As the visitor continues scrolling after the full-screen presentation, the image should smoothly return to its original desktop-screen position.

The desktop device should reappear, with the screenshot fitting correctly inside its screen.

This reverse transition is mandatory.
